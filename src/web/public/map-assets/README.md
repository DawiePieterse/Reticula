# Map style assets

Glyphs and sprites for the offline vector basemap, copied from
[protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) so labels and icons draw without a connection.

- `fonts/`: Noto Sans Regular, Medium and Italic, Latin ranges only (0-255, 256-511, 8192-8447). SIL Open Font License, see `fonts/OFL.txt`.
- `sprites/v4/`: the light spritesheet, derived from the MIT-licensed [tangrams/icons](https://github.com/tangrams/icons/blob/master/LICENSE.md).

Labels in other scripts fall back to missing glyphs. Add their ranges here if a project needs them.
